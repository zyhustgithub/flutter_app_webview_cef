日期：2026-09-16。环境：Windows x64，Flutter 3.47.2 / Dart 3.13.2，
webview_cef 0.6.2 本地分支，CEF 149.0.4。保留项目原有软件 OSR 配置。

| 验证项 | 结果 |
| --- | --- |
| Dart 静态分析：应用、测试、冒烟入口、本地插件 lib | 通过，无问题 |
| Flutter 首页 widget 测试 | 通过 |
| C++ 原生测试 | 通过：100/125/150/200% 坐标、变换、换行/末尾/空矩形、焦点代次、组合/提交/取消 |
| 渲染器 JavaScript 语法检查 | 通过 |

| 正式入口 Debug / Release 构建 | 均通过，已恢复 lib/main.dart |

真实 CEF 冒烟测试记录在 `build/ime_smoke.json`，覆盖单行、多行首行、普通
iframe、不同来源 data iframe、失焦清理、重新聚焦、第二个浏览器获得输入
所有权及非活动浏览器不能夺回所有权。测试通过本地打包 HTML 文件运行。

测试期间修复了两类额外问题：测试初始 data URL 停留在 about:blank，以及原
JavaScript 执行接口从非 CEF UI 线程读取浏览器状态。测试页改为本地文件，
Windows 浏览器操作显式转到 CEF UI 线程。后台测试通过 controller 管理输入
所有权，隔离桌面自动激活状态；它不模拟微软拼音。

**尚未人工验收：**微软拼音真实候选窗口显示、拼音与汉字提交、快捷键/剪贴板、
真实点击与弹窗焦点切换、不同系统 DPI 的目视效果以及跨显示器移动。
自动测试中的 DPI 换算通过不代表这些系统界面场景已经通过。

构建、测试和人工验收步骤见 [Windows 输入法维护与验收](windows-ime.md)。
